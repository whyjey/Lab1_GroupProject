# Контракт бібліотеки Polynomials (Студент Б)

Цей SDK містить динамічну бібліотеку (DLL) для роботи з поліномами. Реалізовано обчислення значення полінома, знаходження його похідної та базовий пошук коренів.

## Загальні технічні деталі
- **Версія API:** 1.0
- **Тип бібліотеки:** Динамічна (Shared / DLL)
- **Підтримка зв'язування:** Неявне (Implicit, через .dll.a) та Явне (Explicit, через LoadLibrary)
- **ABI:** Використовується C-ABI (`extern "C"`). C++ Name Mangling вимкнено для забезпечення сумісності з `GetProcAddress`.

---

## Опис API (Специфікація функцій)

### 1. `evaluate`
- **Сигнатура:** `double evaluate(const double* coeffs, int degree, double x)`
- **Призначення:** Обчислює значення полінома в заданій точці `x`.
- **Параметри:**
    - `coeffs` - вказівник на масив коефіцієнтів полінома (від вільного члена $x^0$ до $x^{degree}$).
    - `degree` - степінь полінома.
    - `x` - точка, в якій обчислюється значення.
- **Повертає:** Значення типу `double`.
- **Граничні умови:** Вказівник `coeffs` не повинен бути `nullptr`. `degree` має бути $\ge 0$.

### 2. `derivative`
- **Сигнатура:** `void derivative(const double* coeffs, int degree, double* out_coeffs)`
- **Призначення:** Знаходить коефіцієнти похідної заданого полінома.
- **Параметри:**
    - `coeffs` - вхідний масив коефіцієнтів.
    - `degree` - степінь вихідного полінома.
    - `out_coeffs` - попередньо виділений масив для запису результату. Його розмір має бути не меншим за `degree`.
